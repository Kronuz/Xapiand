<div class="kz-lede">Xapiand is a <em>fast</em>, <em>simple</em> and <em>modern</em> search and storage server built for the cloud.</div>

<div class="kz-features">
	<div class="kz-feature">

		<p>A straightforward <em>RESTful API</em>, <em>JSON</em> document oriented, with no need for upfront schema definition.</p>
		<a href="/Xapiand/quickstart/">Quick-start →</a>
	</div>
	<div class="kz-feature">
		<h2>😎 Modern</h2>
		<p><em>Real Time Search</em> and data <em>Storage</em>, with <em>Multi&#8209;Tenant</em> indexes that nest and a search that spans many of them.</p>
		<a href="/Xapiand/welcome/">Getting Started →</a>
	</div>
	<div class="kz-feature">
		<h2>🚀 Fast</h2>
		<p>Xapiand is <em>fast</em>, it searches with <a href="https://github.com/Kronuz/strata">strata</a>, its own MIT&#8209;licensed search engine.</p>
		<a href="/Xapiand/architecture/">Architecture →</a>
	</div>

<div class="kz-features">
	<div class="kz-feature">
		<h2>🍂 Lightweight</h2>
		<p>Written in modern <em>C++</em>, it runs as <em>one process</em>: the server, the search engine and the storage, with no separate services to run.</p>
		<a href="/Xapiand/options/">Options →</a>
	</div>
	<div class="kz-feature">
		<h2>⚖️ Sharded</h2>
		<p>Splits each index into <em>Shards</em> on a single <em>Node</em>, keeps a <em>Write&#8209;Ahead Log</em> for recovery, and serves <em>HTTPS</em>.</p>
		<a href="/Xapiand/basics/#shard">Shards →</a>
	</div>
	<div class="kz-feature">
		<h2>🌎 Geo-spatial</h2>
		<p>The integrated hierarchical triangular mesh combines <em>Geolocation</em> with <em>Full&#8209;text Search</em> and <em>Analytics</em>.</p>
		<a href="/Xapiand/tutorials/spatial-search/">Spatial Search →</a>
